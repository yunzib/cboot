# DTO 校验

`cboot.validation` 是基础包，不是契约组件：应用 `import` 后直接使用，
不需要在 `components` 中选择。HTTP body DTO 会在绑定后自动校验。

## 1. 使用

```cpp
import cboot.app;   // 已 re-export cboot.validation

struct CreateUser {
    [[=validation::NotBlank{}]] std::string name;
    [[=validation::Range{.min = 18, .max = 120}]] int age{};
};

class [[=Bean{}]] UserApi {
public:
    [[=Post{"/users"}]]
    Response create(const CreateUser& in) {
        return json_response(in);
    }
};
```

非法请求：

```json
POST /users
{"name":"  ","age":17}
```

返回 `400`：

```json
{
  "errors": [
    {"field": "name", "message": "must not be blank"},
    {"field": "age", "message": "must be between 18 and 120"}
  ]
}
```

JSON 语法错误、字段类型错误同样返回 `400`，错误列表中的 `field` 为
`"body"`。

## 2. 注解

| 注解 | 适用字段 | 说明 |
|---|---|---|
| `validation::NotBlank{}` | `std::string` | 不能为空或全空白 |
| `validation::Range{.min, .max}` | 整数 / 浮点 | 闭区间 `[min, max]` |

自定义文案：

```cpp
struct CreateUser {
    [[=validation::NotBlank{"name required"}]] std::string name;
    [[=validation::Range{.min = 1, .max = 5, .message = "score 1..5"}]]
    double score{};
};
```

`Range::min` 必须小于等于 `max`，否则编译期报错。

## 3. 手动校验

非 HTTP 场景可以直接调用：

```cpp
auto errors = validation::validate(dto);
if (!errors.empty()) {
    for (const auto& e : errors)
        std::println("{}: {}", e.field, e.message);
}

// 或失败即抛 validation::invalid
validation::validate_or_throw(dto);
```

`validation::invalid::errors()` 返回全部字段错误；错误按成员声明序排列。

## 4. 边界

- 只校验顶层字段，不递归嵌套 DTO
- `NotBlank` 只支持 `std::string`
- `Range` 只支持非 bool 整数和浮点
- 不提供自定义 validator 注册表、正则、跨字段校验、国际化
- 非法 body 的 400 映射只发生在 HTTP body DTO 绑定路径；
  路径参数转换失败仍按既有逻辑处理

## 5. 构建

`cboot.validation` 随基础包一起安装导出：

```cmake
find_package(cboot REQUIRED)
target_link_libraries(app PRIVATE cboot::app)
```

只需要校验模块时也可以直接链接：

```cmake
target_link_libraries(app PRIVATE cboot::validation)
```

```cpp
import cboot.validation;
```
